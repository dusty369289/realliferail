# Bundled data

## stations.json

Unchanged copy of `stations.json` from https://github.com/davwheat/uk-railway-stations, fetched 2026-11-07. It holds the
name, CRS code and latitude and longitude of 2609 GB stations.

Licence: Open Database License (ODbL). Attribution: David Wheatley (davwheat), Trainline EU
(https://github.com/trainline-eu/stations) and their sources. If you change it, the changed version must be published
under the ODbL too.

To refresh it, download the same file again. A token holder can also check it against RTT's `/data/stops` (one call).
